Multimodal Sensor Suite & Cranial Pruning

Standard clinical monitoring requires 18 to 22 wet scalp EEG electrodes, which are socially stigmatizing and uncomfortable. EpiPredict introduces a two-stage channel-aware Set Transformer that prunes the cranial montage down to a mean of 2.8 channels per patient while maintaining 80.1% sensitivity and 0.11 FPR/h. To compensate for scalp EEG motion vulnerability, discrete fNIRS optodes measure local preictal surges in oxyhemoglobin (HbO_2) and deoxyhemoglobin (HbR).

Spiking Neural Network (SPCLU) & LIF Dynamics

Event-driven neuromorphic membrane updates discretized via forward Euler (\Delta t = 16ms, \beta \approx 0.45)

// LIF Membrane Potential Update
u[t] = β * u[t-1] + W * x[t-1] - z[t-1] * u_thr
// Heaviside Spike Generation
z[t] = Θ(u[t] - u_thr) = 1 if u[t] ≥ u_thr else 0
// Fast-Sigmoid Surrogate Gradient (BPTT)
&partial;S / &partial;V ≈ 1 / (1 + β_sg * |V[t] - u_thr|)²
// L2 Firing-Rate Sparsity Penalty
L_total = L_CE + λ * ∑ (½ ∑ z[t] - r_target)²
Surrogate Gradient Learning: Because the true derivative of the Heaviside step function is zero everywhere (except at threshold where it is infinite), standard backpropagation fails. Substituting the fast-sigmoid surrogate during backward passes enables end-to-end AdamW optimization while maintaining binary event-driven spike execution during forward passes.

AURA On-Device Continuous Personalization Loop

Because preictal signatures vary between individuals, EpiPredict incorporates the AURA (Adaptive Unlabeled Real-time Approximate-learning) framework. When an embedded high-specificity detector identifies an active seizure onset, it retroactively labels the buffered preictal window and fine-tunes the plastic output layer on-chip using a single recorded seizure.

Feedback Calibration Gain: Reduces false alarm rate by 15% - 20% over 30 days without raw data cloud transmission.
